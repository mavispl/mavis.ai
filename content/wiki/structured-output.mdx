The difference from asking for JSON in a prompt is enforcement. A prompt is a request the model usually honours; a schema constraint is a guarantee about shape. Prompt-based parsing fails intermittently — a preamble, a code fence, a trailing comma — and those failures cluster on unusual inputs.

Schema design decides how the model fails. A required field the source document does not contain forces an invention; make it optional or add an explicit absence variant, and an invented value becomes a correct "not found".
