The only channel for anything the training data lacks. Two edges behave differently: input alone exceeding the window returns a 400, while generation that *reaches* the limit stops with a distinct stop reason and returns a truncated response that looks complete unless you check.

Caching changes what you pay for a prefix, never whether it occupies the window. It is a cost optimisation, not a capacity one.
